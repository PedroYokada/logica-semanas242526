Quiz e desafios no terminal

Programa interativo, input(), decisões, for, while, listas, índices e pontuação.

1

Perguntar

input() apresenta uma pergunta e recebe uma entrada.

2

Verificar

if / elif / else decide o que fazer com a resposta.

3

Repetir

for quando a quantidade é conhecida; while quando depende de uma condição.

FOR

Quantidade conhecida

for i in range(5):
    print(i)

O programa sabe antes de começar quantas repetições serão feitas.

WHILE

Condição que muda

tentativas = 3
while tentativas > 0:
    tentativas -= 1

A repetição continua enquanto a condição permanecer verdadeira.

Listas paralelas:quando perguntas e respostas estão em listas diferentes, o mesmo índice conecta os itens correspondentes. A ordem precisa ser mantida.

Quiz de ciências — acompanhe o fluxo

Leitura + raciocínio

Observe as listas, o índice i, a variável pontos e a ordem das condições. Não é necessário executar o código.

perguntas = [
    "Qual planeta é conhecido como planeta vermelho?",
    "Qual é o maior planeta do Sistema Solar?",
    "Quantas câmaras possui o coração humano?",
    "Qual gás as plantas absorvem na fotossíntese?",
    "Qual é a fórmula química da água?"
]

respostas = [
    "marte",
    "júpiter",
    "4",
    "dióxido de carbono",
    "h2o"
]

pontos = 0

for i in range(5):
    resposta = input(perguntas[i] + " ")

    if resposta.strip().lower() == respostas[i].lower():
        pontos += 1

print("Pontuação final:", pontos)

if pontos == 5:
    print("Perfeito!")
elif pontos >= 3:
    print("Bom trabalho!")
elif pontos >= 1:
    print("Continue tentando.")
else:
    print("Estude mais um pouco.")

Papelaria Ponto Certo — memória e persistência

Leitura + raciocínio

Analise como as funções dividem responsabilidades e como o arquivo vendas.csv representa persistência fora da memória do programa.

import csv
import os

def salvar_vendas(vendas):
    with open("vendas.csv", "w", newline="", encoding="utf-8") as arquivo:
        escritor = csv.writer(arquivo)
        escritor.writerow(["produto", "quantidade", "data"])
        escritor.writerows(vendas)

def carregar_vendas():
    if not os.path.exists("vendas.csv"):
        return []

    vendas = []
    with open("vendas.csv", "r", encoding="utf-8") as arquivo:
        leitor = csv.reader(arquivo)
        next(leitor, None)
        for linha in leitor:
            vendas.append(linha)
    return vendas

def registrar_venda(produtos, vendas):
    nome = input("Produto: ")
    quantidade = int(input("Quantidade: "))

    if quantidade <= 0:
        print("Quantidade inválida.")
        return

    vendas.append([nome, quantidade])
    salvar_vendas(vendas)

def produto_existe(produtos, nome):
    for produto in produtos:
